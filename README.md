# 초보 정령사의 마왕 토벌전 · 체험판

15종 정령을 모아 진화시키고 마왕에게 도전하는 무료 파일럿입니다.
저장소 About의 Website 주소에서 플레이할 수 있습니다.

- 이동: WASD·방향키 또는 전장 드래그
- 사격: 자동, 술식·지원: 준비된 정령 초상 탭 또는 숫자 1–5
- 일시정지: 정지 버튼 또는 Escape
- 마도서: 3전 승리 후 첫 선택 무료, 6·8전 후 골드 구매, 보유 화면에서 강화

저장은 브라우저와 사이트 주소별로 보관됩니다. 다른 주소의 기존 저장이 자동으로 옮겨지지는 않습니다.
진행 중이던 구형 도전은 기존 규칙으로 이어지고, 새 도전에서 마도서를 사용합니다.

불편한 점은 [이 저장소의 Issues](https://github.com/bluehige/spirit-play/issues)에 남겨 주세요.
기기·브라우저, 발생 단계와 재현 방법을 함께 적으면 도움이 됩니다. 개인 정보는 적지 마세요.

이 저장소에는 플레이에 필요한 Web 출력만 있습니다. 개발 소스·기획·검수 자료는 포함하지 않습니다.
실행에 필요한 클라이언트 리소스는 브라우저로 내려받으므로 추출될 수 있습니다.
사용한 엔진·글꼴의 고지는 LICENSES 폴더에 있습니다.
